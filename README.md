Project Title:
Multi-Functional Console-Based Calculator Using x86 Assembly (Irvine32 Library)

Project Description:
This project is a menu-driven console calculator developed in x86 Assembly Language using the Irvine32 library. It provides multiple arithmetic and logical operations including addition, subtraction, multiplication, division (with decimal approximation), modulus, power, factorial, prime number checking, and palindrome checking.
The system takes user input through an interactive menu and performs low-level computation using assembly procedures for each operation, ensuring efficient and optimized processing at the CPU instruction level. It demonstrates core computer architecture concepts such as register usage, loops, conditionals, stack operations, and procedure calls.The calculator also includes error handling for invalid inputs such as division by zero, negative factorials, and unsupported power operations, making it more robust and user-friendly.

Key Features:
Basic arithmetic operations ( +, −, ×, ÷ )
Advanced operations (Factorial, Power, Modulus)
Number property checks (Prime, Palindrome)
Decimal handling for division results
Modular procedure-based design
Menu-driven user interface in console

Learning Outcome:
This project helps in understanding low-level programming, CPU-level computation, and structured problem-solving using assembly language. It strengthens concepts of registers, arithmetic logic operations, loops, and control flow in computer architecture.
